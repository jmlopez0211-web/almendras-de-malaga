# Fotografías de productos

Esta carpeta se reserva para fotografías propias o de terceros con licencia comercial comprobada.

Para la Fase 1, usar `frutos-secos/`. Cada archivo debe corresponder a una sola variedad y preparación; no reutilizar fotografías entre fichas. Registrar autor, fuente, licencia y cambios cuando corresponda.

No añadir archivos provisionales ni fotografías de referencia de otros productos.
