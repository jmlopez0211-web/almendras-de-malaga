## Criterio
No reutilizar una misma fotografía para distintas preparaciones. Las fotos deben representar exactamente si el cacahuete está crudo/tostado/frito, con o sin piel, con cáscara y si la sal está confirmada. Si la imagen no permite verificar esos atributos, se registra como candidata y no se asigna como imagen verificada.
