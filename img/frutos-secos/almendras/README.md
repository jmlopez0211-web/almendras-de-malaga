# Lote 1 — Almendras

## Criterio
Cada fotografía debe corresponder a la preparación exacta. No se asignan imágenes genéricas a productos cuyo aceite, sal, piel o tostado no pueda verificarse visualmente o mediante la descripción de la fuente.

## Fuentes verificadas/candidatas

- **Almendra cruda pelada** — Blanched almonds.jpg, Wikimedia Commons, autor Nadiatalent, dominio público. Página: https://commons.wikimedia.org/wiki/File:Blanched_almonds.jpg. Verificar que el archivo local se optimice y conservar la atribución de la fuente.
- **Almendra frita repelada (Marcona)** — Almendra marcona.jpg, Tamorlan, CC BY 3.0. La descripción identifica almendra Marcona repelada frita; no confirma aceite ni sal, por lo que no debe asignarse a una ficha que especifique esos atributos. Página: https://commons.wikimedia.org/wiki/File:Almendra_marcona.jpg.
- **Almendras fritas (aperitivo español)** — Almendras fritas, aperitivos (España).jpg, Juan Emilio Prades Bel, CC BY 4.0. La fuente identifica almendras fritas, pero no especifica piel, aceite ni sal. Página: https://commons.wikimedia.org/wiki/Category:Almonds_in_Spain.
