Qué frutos secos elegir para preparar un buen aperitivo

Ideas para preparar aperitivos con almendras, pistachos, anacardos, nueces y mezclas de frutos secos.

Un aperitivo con frutos secos puede ser tan sencillo como combinar varias texturas y sabores. Las almendras, pistachos, anacardos, nueces y otros productos permiten crear mezclas para reuniones, comidas y celebraciones.

Combina sabores y texturas

Mezcla frutos secos tostados, naturales o con sal, según tus preferencias. Puedes combinar almendras, pistachos, anacardos y nueces para conseguir diferentes texturas.

Añade fruta deshidratada

Las pasas, los dátiles y otras frutas deshidratadas aportan contraste dulce. Añade pequeñas cantidades para equilibrar la mezcla sin que un ingrediente domine.

Prepara una mezcla personalizada

Elige varios ingredientes, mezcla cantidades pequeñas y ajusta el resultado. Para servir, utiliza recipientes separados si quieres que cada persona pueda escoger sus favoritos.
